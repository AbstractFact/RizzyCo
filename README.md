# RizzyCo

RizzyCo je studentski projekat, rađen u tročlanom timu iz predmeta ***Arhitektura i projektovanje softvera*** na četvrtoj godini studija. RizzyCo je web aplikacija za igranje popularne društvene igre "Riziko" sa više igrača u realnom vremenu. U implementaciji je korišćen ASP.NET Core na backend-u, AzureSQL baza podataka i React na frontend-u.
