# RizzyCo

RizzyCo je studentski projekat, rađen u tročlanom timu u okviru predmeta ***Arhitektura i projektovanje softvera*** na četvrtoj godini studija. Reč je o web aplikaciji za igranje popularne društvene igre "Riziko" sa više igrača u realnom vremenu. U implementaciji su korišćeni ASP.NET Core na backend-u, AzureSQL baza podataka i React na frontend-u.
